# PT Satya Jaya Raharja

Situs statis. Tidak memakai Node.js. Siap diunggah ke `public_html`.

## Yang diunggah
- `index.html`
- `assets/` (gambar, video pengalaman, `assets/css/style.css`, dan `assets/js/site.js`)
- `.htaccess`
- `.user.ini` (bawaan cPanel, biarkan)
- `robots.txt`
- `sitemap.xml`

Jangan unggah folder `.git` kalau ada.

## Sebelum domain dipakai
1. Backup isi `public_html`.
2. Hapus aplikasi Node.js lama di cPanel untuk domain ini, kalau masih ada.
3. Upload berkas di atas ke `public_html`.
4. Pastikan SSL domain aktif, lalu buka `https://ptsatyajayaraharja.id/`.
5. Cek layar masuk, video rumah kos, chat, formulir WhatsApp, dan peta.
6. Di Google Search Console, daftarkan `https://ptsatyajayaraharja.id/sitemap.xml`.

## Customer service
Chat berjalan di browser. Nomor WhatsApp ada di `assets/js/site.js` pada baris `WHATSAPP`.
