## 🏢 Tentang Perusahaan

**PT Satya Jaya Raharja (SJR)** adalah perseroan terbatas yang bergerak di bidang kontraktor umum (*general contractor*), konstruksi bangunan gedung, renovasi struktur, serta desain arsitektur interior dan eksterior. Didukung oleh legalitas lengkap (NIB, SBU Konstruksi Gedung Hunian & Perkantoran terverifikasi LPJK/Kementerian PUPR, serta pengesahan Kemenkumham), PT SJR telah berpengalaman melayani proyek institusi pemerintah, korporasi swasta, hingga properti residensial komersial.

- **Legalitas Badan Usaha:** Terdaftar resmi di AHU Kemenkumham & OSS RBA.
- **Sertifikasi:** SBU Konstruksi Gedung Hunian (BG001) & Konstruksi Gedung Perkantoran (BG002).
- **Domain Resmi:** [https://ptsatyajayaraharja.id](https://ptsatyajayaraharja.id)

## 🚀 Fitur Utama & Arsitektur UI/UX

Website ini dirancang secara *custom-engineered* dengan standar korporat modern untuk menghadirkan kredibilitas tinggi, konversi klien yang optimal, dan performa *ultra-fast loading*.

### 1. 🧭 Corporate Sticky Glassmorphic Navbar & Mobile Drawer
- **Dynamic Scroll Transition:** Bilah navigasi transparan saat di puncak halaman, lalu bertransisi mulus menjadi efek kaca padat (*glassmorphism* dengan `backdrop-filter: blur(20px)`) dan bayangan dinamis saat digulir ke bawah.
- **Mega-Dropdown Interaktif:** Menu dropdown sub-layanan konstruksi (Gedung Hunian, Perkantoran, Fasilitas Pendidikan, Renovasi, Desain Interior & Eksterior) dengan deskripsi singkat dan indikator visual.
- **Mobile Drawer Nav:** Panel drawer samping ramah sentuhan untuk perangkat smartphone, lengkap dengan akordion interaktif dan tombol Call-to-Action langsung.

### 2. 🏛️ Blueprint Hero Section & Trust Builder Bar
- **Latar Belakang Arsitektural:** Mengombinasikan ilustrasi struktur teknik (*blueprint grid overlay*) dengan kontras visual korporat yang kokoh.
- **Dual Call-to-Action (CTA):** Tombol utama *"Konsultasi Proyek Gratis"* dan tombol sekunder *"Unduh Company Profile (PDF)"*.
- **Live Achievement Bar:** Bar metrik pencapaian (Proyek Selesai, Kepuasan Klien 99.8%, Tim Ahli Bersertifikat, dan Pengalaman Konstruksi) sebagai pembangun kepercayaan instan (*instant trust builder*).

### 3. 🛠️ Bento Grid Construction Services
- Tata letak *Bento Grid* responsif menampilkan 6 pilar layanan utama dengan kartu visual definisi tinggi, efek elevasi halus (*subtle hover lift*), dan tombol penunjuk konsultasi spesifik per kategori.

### 4. 💬 Interactive Live Chat & In-Chat Smart Consultation Form
- **Floating Action Button (FAB):** Tombol chat melayang di pojok kanan bawah dengan animasi *pulse ring* online dan badge notifikasi.
- **Percakapan Interaktif:** Dilengkapi *Quick Suggestion Chips* ("Estimasi Biaya", "Jadwal Survey", "Portofolio", "Konsultasi Cepat") serta simulasi asisten proyek dengan indikator animasi mengetik (*typing indicator*).
- **In-Chat Consultation Form:** Klien dapat mengisi nama, jenis proyek, estimasi anggaran, dan catatan lokasi langsung di dalam kotak obrolan. Form secara otomatis memformat pesan secara rapi dan mengarahkannya ke **WhatsApp resmi PT SJR**.

### 5. 📢 Sequential Rotating Activity Feed Toast (Social Proof)
- Notifikasi melayang (*floating toast*) di sudut kiri bawah layar yang menyajikan testimoni nyata kepuasan klien bintang 5 secara berurutan (*sequential loop*).
- Dilengkapi foto/avatar klien, indikator verified badge (✓), review proyek, animasi *progress bar*, jeda saat kursor diarahkan (*hover pause*), serta kontrol penutup manual.
- Terintegrasi cerdas dengan layar pembuka: hanya muncul setelah pengunjung memasuki website utama.

### 6. 📄 25-Page Corporate Profile Lightbox Viewer
- Galeri interaktif lengkap memuat 25 halaman dokumen Company Profile PT Satya Jaya Raharja, mencakup Akta Pendirian, SK Menkumham, SBU Hunian & Perkantoran, NPWP, NIB, Struktur Organisasi, dan Peralatan Kerja.
- Navigasi mulus dengan tombol panah (*prev/next*), keyboard shortcut (`ArrowLeft`, `ArrowRight`, `Escape`), dan kontrol responsif.

### 7. 🎬 Project Experience Gallery & Video Showcase
- Dokumentasi video langsung proyek pembangunan (misal: *Pembangunan Rumah Kos 2 Lantai*) dengan pemutar terintegrasi.
- Galeri foto progres lapangan komprehensif mulai dari struktur besi beton, pemasangan rangka atap, hingga tahap penyelesaian akhir (*finishing*).

### 8. 🤝 Infinite Partner & Client Logo Marquee
- Barisan logo klien dan mitra institusional ternama (Korlantas Polri, Skadron Udara TNI AU, SPN Polda Metro Jaya, Yayasan Yasarini, PT Berlian Cipta Boga, dll.) yang berjalan otomatis tanpa jeda (*infinite CSS marquee*).

## 🔒 Audit & Standar Keamanan Cyber (.htaccess Hardening)

Berkas [.htaccess](.htaccess) telah dikonfigurasi secara ketat mengikuti rekomendasi **OWASP Web Security Standards**:

1. **Enforce HTTPS (SSL Redirect):**
   Memaksa semua lalu lintas HTTP dialihkan secara otomatis ke sambungan aman HTTPS dengan kode status `301 Permanent Redirect`.

2. **HTTP Strict Transport Security (HSTS):**
   ```apache
   Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"
   ```

3. **Content Security Policy (CSP):**
   Membatasi sumber eksekusi skrip, style, frame, dan media hanya dari sumber terpercaya (`'self'` dan origin Google Maps/WhatsApp).

4. **Pencegahan Clickjacking & MIME Sniffing:**
   - `X-Frame-Options: SAMEORIGIN`
   - `X-Content-Type-Options: nosniff`

5. **Proteksi Berkas Sensitif & Directory Listing:**
   - `Options -Indexes` untuk mencegah pengunjung melihat isi folder secara terbuka.
   - Pemblokiran akses langsung terhadap berkas tersembunyi (`.git`, `.env`, `.htaccess`, `.ini`).

6. **Kompresi Gzip / Brotli & Cache Control:**
   - Kompresi aktif untuk berkas `text/html`, `text/css`, `application/javascript`, dan `image/svg+xml`.
   - Penerapan `Cache-Control` optimal untuk aset statis dengan dukungan *cache-busting query parameter*.

## 📦 Panduan Instalasi & Deployment (cPanel / Apache)

### Cara 1: Clone Melalui Git (cPanel Git Version Control)
1. Buka **cPanel** > menu **Git™ Version Control**.
2. Klik **Create**, lalu masukkan Clone URL:
   ```text
   https://github.com/RaihanPrnwd/PT-SATYA-JAYA-RAHARJA.git
   ```
3. Tentukan Repository Path ke direktori `public_html/`.
4. Klik **Create** dan lakukan **Deploy HEAD Commit**.

### Cara 2: Upload Manual Berkas
1. Pastikan seluruh berkas telah di-push atau diunduh dari repositori ini.
2. Salin seluruh konten ke dalam folder `public_html/` domain Anda.
3. Pastikan berkas `.htaccess` ikut terunggah (aktifkan opsi *"Show Hidden Files"* pada cPanel File Manager).
4. Akses situs melalui peramban: `https://ptsatyajayaraharja.id/`.
